# 商机管家 · 客户商机管理 App

一个手机优先的客户关系管理（CRM）应用，用于记录**客户基本信息**、管理**商机进度**（线索 → 需求 → 意向 → 方案 → 报价 → 投标 → 签单），并记录**每次联系 / 拜访客户的跟进记录**。

> 无需安装任何软件、无需注册账号。数据保存在手机/电脑浏览器本地，可随时导出备份。

---

## ✨ 功能一览

| 模块 | 功能 |
| --- | --- |
| 🏠 首页 | 客户数 / 进行中商机 / 待跟进 / 本月签单金额统计；商机漏斗图；待跟进提醒（逾期、今天、7天内）；从未跟进的客户提醒 |
| 👤 客户 | 姓名、联系人、电话、公司、行业、来源、等级、地址、备注；搜索；一键拨号；删除时级联清理关联数据 |
| 🎯 商机 | 七大阶段（线索→需求→意向→方案→报价→投标→签单）+ 输单；阶段一键推进/回退；阶段变更历史时间线；预计金额与成交日期；7 段进度圆点 |
| 📝 跟进 | 电话 / 微信 / 拜访 / 邮件 / 其他；关联客户与商机；下次跟进日期提醒；按类型筛选、搜索 |
| 💾 我的 | 本月统计；JSON 备份导出/导入；客户表格导出 CSV（可用 Excel 打开）；示例数据；清空数据 |

## 🚀 快速开始

### 方式一：电脑直接使用（最简单）
双击 `index.html`，用浏览器打开即可使用（Chrome / Edge 均可）。

### 方式二：一键启动本地服务器（推荐，手机也能用）
双击 **`启动服务器.bat`**（需要电脑装有 Python），然后在同一 WiFi 下：
- 电脑访问：`http://localhost:8000`
- 手机访问：`http://电脑IP:8000`（电脑 IP 用命令 `ipconfig` 查看，如 `http://192.168.1.100:8000`）

## 🌐 部署到公网（随时随地用）

**推荐使用单文件版**：`商机管家-单文件版.html` —— 样式、脚本、图标全部打包在一个文件里（约 140KB），**只需上传这一个文件**，不存在"文件没传全"的问题。

### 方案一：GitHub Pages（免费 · 有 HTTPS · 最推荐）

1. 注册/登录 [github.com](https://github.com)（免费）
2. 点右上角 **+ → New repository**，仓库名随意（如 `crm`），选 **Public**，点 Create
3. 进入仓库 → **Add file → Upload files** → 把 `商机管家-单文件版.html` 拖进去，**重命名为 `index.html`** → Commit changes
4. 仓库页点 **Settings → Pages** → 「Source」选 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)** → Save
5. 等待 1~2 分钟，页面上方会显示网址：`https://你的用户名.github.io/crm/`
6. 手机浏览器打开这个网址，**分享 → 添加到主屏幕**，就变成一个独立 App 图标了

> GitHub Pages 国内可以直接访问（偶尔慢），自带 HTTPS，可安装到桌面、可用示例数据体验。

### 方案二：腾讯云 COS / 阿里云 OSS（国内访问最快）

1. 注册并实名认证腾讯云或阿里云（有免费额度，新用户一般够用几年）
2. 创建存储桶 → 开启**静态网站托管** → 上传 `商机管家-单文件版.html` 并重命名为 `index.html`
3. 用系统分配的默认域名访问（无需备案；绑定自己的域名则需要备案）

### 方案三：Cloudflare Pages（免费 · 无限流量）

1. 注册 [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Pages → Direct Upload
2. 上传 `商机管家-单文件版.html`（重命名为 `index.html`）→ 得到 `https://xxx.pages.dev` 网址

### ⚠️ 部署后如果"只显示图标、点不动"

那是**脚本没有加载成功**，常见原因和解决办法：

| 原因 | 解决办法 |
| --- | --- |
| 只上传了 `index.html`，漏传了 style.css / app.js | 改用**单文件版**（一个文件全包含） |
| 上传/打开了旧文件或 GitHub 代码页（源码页看起来也是"一页"） | 确认打开的是 `https://用户名.github.io/仓库名/` 这个网址 |
| 浏览器缓存了旧版本 | 手机浏览器设置里清除该网站缓存，或用无痕窗口打开 |
| 浏览器内核过旧（老微信内置浏览器、旧安卓 WebView） | 已做兼容修复；或改用系统浏览器 / 升级微信 |

> 本应用已内置**错误自诊断**：如果脚本运行出错，页面顶部会显示红色错误条并写明具体原因。再遇到问题时请把红色错误条截图发来，可快速定位。

## 📱 安装到手机桌面（像 App 一样用）

通过 **https 网址**打开应用后：

- **iPhone（Safari）**：点底部「分享」按钮 → 「添加到主屏幕」
- **Android（Chrome）**：点右上角菜单 → 「安装应用 / 添加到主屏幕」

安装后可从桌面图标全屏启动，体验与原生 App 一致。

> 注意：直接双击打开的 `file://` 页面无法安装到桌面，需要走网址（http/https）。

## 💾 数据说明

- 所有数据保存在**当前浏览器的本地存储**中，不会上传到任何服务器；
- **不同手机/浏览器之间数据不互通**（各自的本地存储），换设备请用「我的 → 导出数据备份」+ 新设备「导入」迁移；
- 更换手机 / 清除浏览器数据会**丢失记录**，请定期导出 JSON 备份；
- 「导出客户表格（CSV）」可直接用 Excel / WPS 打开。
