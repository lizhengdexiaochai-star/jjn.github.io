# 商机管家 · 客户商机管理

手机优先的客户商机管理应用：记录客户基本信息、商机进度（线索→需求→意向→方案→报价→投标→签单）和每次联系/拜访记录。数据保存在各自浏览器本地，无服务器、无广告、无数据上传。

> 本仓库只包含一个应用文件 `index.html`（约 140KB，样式/脚本/图标已全部打包在内）。

## 🚀 发布到 GitHub Pages（5 分钟）

1. 把本仓库的两个文件（`index.html` 和本 `README.md`）上传到你的 GitHub 仓库根目录
   - 网页上传：仓库页 → **Add file → Upload files** → 拖入文件 → Commit changes
2. 仓库页 → **Settings → Pages**
3. 「Build and deployment → Source」选 **Deploy from a branch**
4. Branch 选 **main**，目录选 **/ (root)** → 点 **Save**
5. 等 1~2 分钟，页面上方会出现网址：`https://你的用户名.github.io/仓库名/`

手机打开该网址 → Safari「分享 → 添加到主屏幕」/ Chrome「安装应用」，即变成独立 App。

## ❓ 页面打不开 / 只显示图标？

- 确认访问的是 `https://用户名.github.io/仓库名/`，而不是 GitHub 仓库代码页（代码页显示的是源码）
- 部署后有 1~2 分钟生效延迟，且浏览器可能有缓存：请**清除该网站缓存**后刷新，或用无痕窗口打开
- 本应用内置错误自诊断：如果脚本运行出错，页面顶部会显示红色错误条并写明具体原因，请截图反馈
- 浏览器过旧（安卓 6 以下 / 微信老内置浏览器）可能不兼容，请改用系统浏览器

## 📱 使用说明

- 首页：统计看板、商机漏斗、待跟进提醒（逾期/今天/7天内）
- 客户：基本信息、一键拨号、关联商机与跟进记录
- 商机：七大阶段一键推进/回退、阶段历史、金额与成交日期
- 跟进：电话/微信/拜访/邮件记录，设置下次跟进日期自动提醒
- 我的：JSON 备份导出/导入（换设备迁移）、客户表格导出 CSV、示例数据

## 💾 数据说明

- 数据保存在**每个设备各自的浏览器本地**，不上传任何服务器，不同设备不互通
- 换设备：旧设备「我的 → 导出数据备份」→ 新设备「导入数据备份」
- 定期导出备份；清除浏览器数据会丢失记录
